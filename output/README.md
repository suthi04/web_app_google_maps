# Research document artifacts

ไฟล์ในโฟลเดอร์นี้ไม่ถูกใช้โดยเว็บแอป แต่เก็บไว้เป็นงานส่งและต้นฉบับงานวิจัย

| ไฟล์ | สถานะ |
|---|---|
| `thesis-v100.html` | ต้นฉบับ Version 1.0 ที่มี PDF คู่กัน |
| `InsightReview-Thesis-v100.pdf` | PDF ที่สร้างจากต้นฉบับ v100 และถูกอ้างจากเอกสารวิจัย |
| `thesis-v2.html` | ร่างที่ใหม่กว่าและละเอียดกว่า v100; ยังไม่มี PDF คู่กันและต้องตรวจเนื้อหาให้ตรงโค้ดล่าสุดก่อนประกาศเป็นฉบับหลัก |
| `review-summary.html` | ต้นฉบับรายงานตรวจสอบความสอดคล้อง |
| `InsightReview-Review-Summary.pdf` | PDF ของรายงานตรวจสอบ |

ห้ามลบ v100 จนกว่า v2 จะผ่านการตรวจและสร้าง PDF สำเร็จ หลังจากนั้นจึงย้าย v100
ไป archive หรือถอดออกได้ โดยควรใช้ชื่อกลาง เช่น `thesis.html` และ `thesis.pdf`
